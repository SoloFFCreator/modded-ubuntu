A lightweight, fully featured Modded Ubuntu environment for Android. Includes VS Code, Browsers, and Audio Fixes.

Features

Fixed Audio

Audio output issues fixed. Enjoy sound directly from your Termux environment.

VS Code

Pre-installed Visual Studio Code for development on the go.

Browsers

Includes Chromium and Mozilla Firefox browsers for full web access.

Lightweight

Optimized for performance. Requires at least 4GB of storage.

Bangla Fonts

Native support for Bangla fonts included out of the box.

Hacking Tools

Includes Katoolin3 tool for installing Kali Linux tools easily.

Installation

Open Termux and run the following commands:

pkg update -y && pkg upgrade -y
pkg install git wget -y
git clone https://github.com/SoloFFCreator/modded-ubuntu.git
cd modded-ubuntu
bash setup.sh

Note: During installation, you may be asked to allow storage permissions. Ensure you have a stable internet connection.

How to Use

1. Setup User

After installation, restart Termux and create your user:

ubuntu
bash user.sh

2. Start GUI

To start the graphical interface (VNC Server):

ubuntu
bash gui.sh

Note down the VNC password you set!

3. Connect

Open VNC Viewer app on your phone:

  • Address: localhost:1
  • Name: Ubuntu
  • Password: The one you created earlier.

Stop Server

vncstop
